# Security reporting

The port is under development; no supported public release has been declared.

For a vulnerability, use the repository's private vulnerability reporting feature if enabled.
Otherwise contact a maintainer privately using their published contact information before sharing
exploit details publicly. This repository has not yet established a dedicated security contact or
response schedule; these must be configured before a public release.

Include the affected commit/version, target, input/config/resource needed to reproduce the issue,
and observed effect. Dictionary/config/ZIP readers and host filesystem adapters are relevant attack
surfaces. Do not include credentials or unrelated private application data in a report.

Ordinary conversion discrepancies can be reported as public bugs with a minimal test case.
